# Character Archive

보관함 안의 캐릭터 노트를 카드 갤러리로 봅니다. 웹 공유를 직접 실행하지 않는 한 데이터는 로컬 노트에 남습니다.

카드에는 표지, 상태, 관계, 본문, 프롬프트가 보입니다. 자세히 고칠 때는 노트를 엽니다.

> English guide: [README.md](./README.md)

## 할 수 있는 일

- **갤러리** — 아카이브(위쪽 이름)와 그룹(행 제목)으로 카드를 나눕니다.
- **카드** — 표지와 속성을 한눈에 봅니다. 카드를 누르면 피크 패널이 열립니다.
- **속성** — 상태, 관계, 인연, 소속, 태그. 보이는 이름은 갤러리 편집 → **속성 관리**(책 아이콘)에서 바꿉니다.
- **필터** — 위쪽 칩(On / Off 등).
- **표지** — 노트 안의 첫 그림이 카드 표지입니다. 갤러리 편집에서 표지를 누르면 바꿉니다.
- **새 카드** — 신상 표, 외형 / 성격 / 능력, 프롬프트 칸이 있는 시작 시트. 안내 문구만 있고 이미지는 없습니다.
- **추가 창** — 같은 카드를 다른 탭에서 봅니다. 새 하위 그룹을 만들지 않습니다.
- **웹 공유**(선택) — 지금 갤러리를 HTML로 올립니다. 호스팅은 직접 합니다. 원본은 보관함입니다.

## 사용법

1. 플러그인을 켭니다.
2. `Character Archive/Character Archive.md` 를 엽니다. 그 노트가 갤러리가 됩니다.
3. 또는 리본 **격자** 아이콘, 명령 **갤러리 열기**를 씁니다.

명령 팔레트에는 **갤러리 열기**와 **갤러리 편집 켜기 / 끄기** 두 가지만 있습니다. 갤러리 열기는 마지막으로 보던 갤러리를 엽니다. 편집 켜기 / 끄기는 지금 보고 있는 갤러리에만 적용됩니다. 카드 추가와 새 아카이브는 편집 모드에서, 공유는 지구본 버튼에서, 다른 갤러리는 탭의 **더 보기** 메뉴 **새 갤러리 만들기**에서 합니다.

처음에는 **예시** 아카이브에 샘플 카드 **첫 카드** 하나가 생깁니다. 지워도 됩니다.

캐릭터는 라이브러리 폴더 아래 `kind: character` 노트입니다.

연필을 켜면 카드 이동·캐릭터 추가·속성 편집을 합니다. 연필을 끄면 읽기 전용입니다.

`##` 제목과 표는 갤러리가 읽습니다. `## 메모` 는 노트에만 두고 피크에는 안 보입니다.

아무 노트에나 갤러리를 넣으려면:

````md
```charinfo
```
````

## 설치

### 커뮤니티 플러그인

1. **설정 → 커뮤니티 플러그인**을 엽니다.
2. **Character Archive**를 찾아 설치합니다.
3. 설치 후 켭니다.

### 수동 설치

1. [Releases](https://github.com/laillei-plugins/character-archive/releases)에서 `main.js`, `manifest.json`, `styles.css`를 받습니다.
2. `<보관함>/.obsidian/plugins/character-archive/`에 넣습니다.
3. 커뮤니티 플러그인에서 **Character Archive**를 켭니다.

## 웹 공유

웹 공유는 선택 기능이며, 사용자가 게시 버튼을 눌렀을 때만 실행됩니다. 지구본 버튼에서 포함할 카드와 옆 패널 항목을 직접 고릅니다. 게시하면 선택한 카드 정보, 선택한 노트 구역, 선택한 프롬프트와 포함된 표지가 공개 HTML 페이지로 업로드됩니다. 링크가 있는 사람은 누구나 볼 수 있습니다.

기본값은 관리자가 운영하는 `https://character-archive.pages.dev` 공유 서버입니다. 계정 없이 새 공유를 만들 수 있지만, 기존 페이지를 바꾸거나 지우려면 플러그인이 따로 저장한 관리 열쇠가 필요합니다. 기본 유지 기간은 30일이며 7일, 30일, 1년 중에서 고를 수 있습니다. 같은 갤러리 또는 캐릭터 공유에서 호스팅 공유를 중지할 수도 있습니다. 직접 운영하는 Cloudflare 호스트나 GitHub Pages를 대신 사용할 수 있습니다.

일반 갤러리 사용에는 텔레메트리가 없고 공유 업로드도 발생하지 않습니다. 네트워크 사용, 보관 기간, 인증 정보와 삭제 방식은 [Privacy](./PRIVACY.md)를 확인하세요.
