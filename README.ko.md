# Character Archive

보관함 안의 캐릭터 노트를 카드 갤러리로 봅니다. 데이터는 로컬 노트에 남습니다.

카드에는 표지, 상태, 관계, 본문, 프롬프트가 보입니다. 자세히 고칠 때는 노트를 엽니다.

> English guide: [README.md](./README.md)

## 할 수 있는 일

- **갤러리** — 아카이브(위쪽 이름)와 그룹(행 제목)으로 카드를 나눕니다.
- **카드** — 표지와 속성을 한눈에 봅니다. 카드를 누르면 피크 패널이 열립니다.
- **속성** — 상태, 관계, 인연, 소속, 태그. 보이는 이름은 갤러리 편집 → **속성 관리**(책 아이콘)에서 바꿉니다.
- **필터** — 위쪽 칩(On / Off 등).
- **표지** — 노트 안의 첫 그림이 카드 표지입니다. 갤러리 편집에서 표지를 누르면 바꿉니다.
- **새 카드** — 신상 표, 외형 / 성격 / 능력, 프롬프트 칸이 있는 시작 시트. 안내 문구만 있고 이미지는 없습니다.
- **추가 창** — 같은 카드를 다른 탭에서 봅니다. 새 하위 그룹을 만들지 않습니다.
- **웹 공유**(선택) — 지금 갤러리를 HTML로 올립니다. 호스팅은 직접 합니다. 원본은 보관함입니다.

## 사용법

1. 플러그인을 켭니다.
2. `Character Archive/Character Archive.md` 를 엽니다. 그 노트가 갤러리가 됩니다.
3. 또는 리본 **격자** 아이콘, 명령 **갤러리 열기** / **기본 갤러리 열기**를 씁니다.

처음에는 **예시** 아카이브에 샘플 카드 **첫 카드** 하나가 생깁니다. 지워도 됩니다.

캐릭터는 라이브러리 폴더 아래 `kind: character` 노트입니다.

연필을 켜면 카드 이동·캐릭터 추가·속성 편집을 합니다. 연필을 끄면 읽기 전용입니다.

`##` 제목과 표는 갤러리가 읽습니다. `## 메모` 는 노트에만 두고 피크에는 안 보입니다.

아무 노트에나 갤러리를 넣으려면:

````md
```charinfo
```
````

## 설치

### 커뮤니티 플러그인

1. **설정 → 커뮤니티 플러그인**을 엽니다.
2. **Character Archive**를 찾아 설치합니다.
3. 설치 후 켭니다.

### 수동 설치

1. [Releases](https://github.com/laillei-plugins/character-archive/releases)에서 `main.js`, `manifest.json`, `styles.css`를 받습니다.
2. `<보관함>/.obsidian/plugins/character-archive/`에 넣습니다.
3. 커뮤니티 플러그인에서 **Character Archive**를 켭니다.

## 웹 공유

지구본 버튼으로 고른 카드를 올립니다. Cloudflare Worker나 GitHub Pages 등으로 직접 호스팅하고, 설정에 주소와 업로드 키를 넣습니다. 이 플러그인은 공개 호스트를 기본으로 제공하지 않습니다.
